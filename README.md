# ☕ Atividades em Java

Repositório dedicado ao armazenamento e organização dos exercícios, atividades práticas e estudos desenvolvidos em **Java**.

---

## 📌 Sobre o Repositório

Este espaço tem como objetivo registrar a minha evolução e aprendizado em desenvolvimento de software orientado a objetos, cobrindo desde conceitos básicos de lógica até estruturas de dados e práticas de código limpo.

---

## 🚀 Tecnologias e Ferramentas Usadas

- **Linguagem:** Java (JDK 17+)
- **IDE:** Visual Studio Code / IntelliJ IDEA / Eclipse
- **Controle de Versão:** Git & GitHub

---

## 🛠️ Conteúdos e Conceitos Praticados

- [x] Sintaxe básica e Entrada/Saída de dados (`Scanner`)
- [x] Estruturas Condicionais (`if`, `else`, `switch-case`)
- [x] Estruturas de Repetição (`for`, `while`, `do-while`)
- [x] Manipulação de Vetores/Arrays e **For-Each**
- [x] Programação Orientada a Objetos (Classes, Atributos e Métodos)
- [x] Construtores, Encapsulamento e Sobrecarga
